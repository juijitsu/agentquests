# Метод · Два шага и их порядок

**Шаг 1. Отберите пригодных.** Проверка идёт по всем кандидатам, а не по
одному:

```python
fit = [d for d in DOCS if model.answers(question, d)]
```

**Шаг 2. Среди них возьмите самого похожего.**

```python
best = max(fit, key=lambda d: model.similarity(question, d["text"]))
```

Похожесть никуда не делась и по-прежнему нужна: пригодных документов может
оказаться несколько, и выбирать среди них надо по близости к вопросу. На этом
уровне их два — прайс по нужному направлению и прайс по чужому.

**Шаг 3. Не меняйте шаги местами.** Сперва взять самого похожего, а потом
проверить его на пригодность — значит остаться ни с чем, когда проверка не
пройдена. Отбор сужает поле, похожесть выбирает лучшего в суженном.

**Шаг 4. Не судите о пригодности сами.** Что считать ответом, зависит от
вопроса: на «сколько» нужно число, на «когда» — дата, на «можно ли» — да или
нет. Это работа модели.

---

Проверка на честность: **уберите из корпуса нужный прайс и прогоните.** Хороший
поиск скажет, что ответа нет. Плохой уверенно вернёт регламент — и это ровно то
же, что вы чините сейчас.
