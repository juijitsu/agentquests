# Метод · Близость вместо совпадения

**Шаг 1. Переведите вопрос и документы в общее пространство.** В этом уровне —
через `model.embed`, в жизни — через модель эмбеддингов. Важно, что **и запрос,
и документы переводятся одинаково**: сравнивать можно только сравнимое.

**Шаг 2. Посчитайте близость к каждому документу.**

```python
model.similarity(question, doc["text"])
```

**Шаг 3. Возьмите лучший.**

```python
best = max(DOCS, key=lambda d: model.similarity(question, d["text"]))
```

`max` с ключом обходит корпус один раз и не требует сортировки: когда нужен
один документ, сортировать весь список незачем.

**Шаг 4. Не подмешивайте слова «на всякий случай».** Соблазн сложить оба
способа велик, и на следующих уровнях мы к этому вернёмся осознанно. Сейчас
смешение только спрячет, работает ли поиск по смыслу.
