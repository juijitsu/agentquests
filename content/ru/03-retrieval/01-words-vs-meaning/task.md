# Поиск · Ограничение не то

Диспетчер спрашивает: какое ограничение веса на мосту Кэрролл.

В корпусе четыре документа, и нужный там есть: «мост Кэрролл: предельная масса
18 т». Агент отвечает про ограничение скорости на I-55.

```
python engine/check.py content/ru/03-retrieval/01-words-vs-meaning/starter/novice/agent.py
```

Посмотрите на первую строку проверки: искали по словам. В вопросе «вес», в
нужном документе «масса» — общих слов нет. Зато слово «ограничение» стоит у
знака скорости, и словарный поиск честно поставил его первым.

**Ищите по смыслу, а не по совпадению слов.**

## Сдано, если

- поиск шёл по смыслу, а не по словам;
- в ответе названы 18 т;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | словарный поиск, в `TODO` названы нужные вызовы |
| `starter/advanced/` | сказано только, что нужный документ в корпусе есть |
| `starter/pro/` | контракт и весь доступный инструментарий |

## Если застряли

`similarity` принимает два текста, а не документы. Документ — это словарь;
сравнивать нужно `doc["text"]`.
