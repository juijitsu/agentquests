# Метод · Набор с проверкой на прибавку

**Шаг 1. Отранжируйте по похожести, как раньше.** Ничего нового: порядок
кандидатов по-прежнему задаёт близость к вопросу.

**Шаг 2. Набирайте по одному и проверяйте повтор.**

```python
if any(model.same_fact(chunk["text"], taken) for taken in picked):
    continue
```

Сравнивать нужно с **каждым уже взятым**, а не только с предыдущим: третий кусок
может повторять первый, минуя второй.

**Шаг 3. Остановитесь по размеру подборки, а не по концу списка.**

```python
if len(picked) == TOP_K:
    break
```

**Шаг 4. Не подменяйте проверку сравнением строк.** `a["text"] == b["text"]`
поймает только буквальные копии. В живом архиве факт повторяется пересказом, а
не копипастой.

---

Проверка на честность: **посчитайте, сколько разных фактов в вашей подборке.**
Если их меньше, чем мест, вы платите местами за повторы.
