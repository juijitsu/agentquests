# Метод · Достроить, потом судить

**Шаг 1. Запросите соседей каждого кандидата.** Инструмент возвращает куски того
же документа по порядку:

```python
run_tool("neighbours", {"id": chunk["id"]})
```

**Шаг 2. Склейте их в один текст.** Порядок важен: «после неё» имеет смысл
только после того предложения, к которому относится.

```python
text = " ".join(c["text"] for c in neighbours)
```

**Шаг 3. Проверяйте на пригодность уже склеенное.** Это главное изменение по
сравнению с прошлым уровнем: судить надо о целом, а не о куске.

**Шаг 4. Похожесть считайте тоже по целому.** Склеенный текст ближе к вопросу,
чем любая из его половин, — потому что в нём наконец есть и мост, и масса.

---

Проверка на честность: **посмотрите, что вы отдаёте на проверку пригодности.**
Если туда уходит `chunk["text"]`, вы всё ещё судите о куске. Если склеенный
текст — о факте.
