# Метод · Разложить, найти, сложить

**Шаг 1. Разложите вопрос.**

```python
for part in model.split(question):
```

Разложение — работа модели: понять, что «и» здесь соединяет два разных вопроса,
а не одно уточняет другое, может только тот, кто понимает смысл.

**Шаг 2. Ищите по каждой части отдельно.**

```python
run_tool("search", {"query": part})
```

Именно отдельно. Склеить части обратно в одну строку и поискать по ней — это
ровно то, с чего начали.

**Шаг 3. Складывайте с отбрасыванием повторов по идентификатору.**

```python
if doc["id"] not in seen:
    seen.add(doc["id"])
    found.append(doc)
```

**Шаг 4. Не обрезайте объединение до размера одной подборки.** Топ-2 задан для
одного запроса. Два запроса законно приносят до четырёх документов, и урезать
их обратно до двух — значит вернуть себе исходную задачу.
