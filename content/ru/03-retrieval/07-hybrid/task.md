# Поиск · Вес чужого груза

Диспетчер спрашивает вес по накладной 4471. Правильный ответ — двадцать четыре
тонны, стекло листовое.

Агент отвечает: девятнадцать. Это накладная 4478, трубы.

```
python engine/check.py content/ru/03-retrieval/07-hybrid/starter/novice/agent.py
```

Посмотрите на вторую строку проверки: выбран не тот документ. Смысловой поиск
отработал безупречно — он нашёл накладную с весом груза. Накладную. С весом.
Просто не ту, потому что для смысла 4471 и 4478 неразличимы.

Вернуть словарный поиск не поможет: письмо «по накладной 4471» совпадает с
вопросом двумя словами, а сама накладная — только номером, потому что в ней
именительный падеж.

**Сузьте точным совпадением по номеру, выберите по смыслу.**

## Сдано, если

- задействованы оба сигнала — точный и смысловой;
- выбрана накладная 4471, а не письмо и не соседняя накладная;
- в ответе названы 24 т;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | выбор по смыслу, в `TODO` названы оба вызова |
| `starter/advanced/` | сказано только, что смысл отработал верно |
| `starter/pro/` | контракт и почему не годится ни один способ поодиночке |

## Если застряли

Точный поиск ищет обозначение, а не вопрос целиком. По всему вопросу он снова
принесёт письмо и платёжку.
