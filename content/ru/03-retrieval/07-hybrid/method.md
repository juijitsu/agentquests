# Метод · Сузить точным, выбрать смыслом

**Шаг 1. Достаньте обозначение из вопроса.**

```python
token = model.identifier(question)
```

Именно у модели: отличить номер накладной от количества тонн по одному виду
строки нельзя, обе состоят из цифр.

**Шаг 2. Сузьте корпус точным совпадением.**

```python
same_number = run_tool("exact", {"token": token})
```

Ищется **обозначение**, а не вопрос целиком. Точный поиск по всему вопросу
вернёт то же, что и раньше: совпадения по падежам и предлогам.

**Шаг 3. Среди суженного выберите по смыслу.**

```python
best = max(same_number, key=lambda d: model.similarity(question, d["text"]))
```

**Шаг 4. Не меняйте шаги местами.** Сперва смысл, потом номер — значит выбирать
из трёх одинаковых и надеяться на порядок в списке.

---

Проверка на честность: **уберите из вопроса номер и посмотрите, что найдётся.**
Если результат тот же — номер в вашем поиске не участвует, и на соседней
накладной вы ошибётесь.
