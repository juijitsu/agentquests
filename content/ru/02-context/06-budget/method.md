# Метод · Жадный набор по отдаче

**Шаг 1. Посчитайте отдачу каждого блока.** Ценность делится на стоимость, а не
сравнивается с ней:

```ts
model.worth(block) / block.cost
```

**Шаг 2. Отсортируйте по убыванию.** Копию, а не исходный массив: `BLOCKS`
принадлежит сценарию, и порядок в нём может понадобиться кому-то ещё.

```ts
const ranked = [...BLOCKS].sort((a, b) => model.worth(b) / b.cost - model.worth(a) / a.cost);
```

**Шаг 3. Набирайте, пока помещается.** Проверка идёт до добавления, а не после:

```ts
if (spent + block.cost <= BUDGET) { ... }
```

**Шаг 4. Не останавливайтесь на первом, который не влез.** Дорогой блок в
середине списка не должен обрывать набор: после него могут идти дешёвые, которые
ещё поместятся. Разница между `continue` и `break` здесь стоит одного блока.

---

Проверка на честность: **удвойте стоимость самого ценного блока и прогоните
отбор заново.** Если бриф не изменился, вы сортируете по ценности, а не по
отдаче, и просто пока везёт.
