# Метод · Максимум внутри группы

**Шаг 1. Назовите ключ.** Это то, внутри чего считается свежесть. Здесь —
`lane`: у каждого направления своя история.

**Шаг 2. Найдите максимум времени при этом же ключе.** Связь между внешним и
внутренним запросом — вся суть приёма:

```sql
WHERE quoted_at = (
  SELECT MAX(quoted_at) FROM rates AS latest WHERE latest.lane = rates.lane
)
```

Уберите условие `latest.lane = rates.lane` — и получится максимум по всей
таблице, то есть та самая неверная починка.

**Шаг 3. Верните только нужные столбцы.** Вопрос про направление и цену; дата
нужна была для отбора, а не для ответа.

**Шаг 4. Уложитесь в один запрос.** Отбор свежего — не многошаговая процедура.
Если получается два запроса, значит вы считаете во втором то, что база умеет
посчитать в первом.

---

Проверка на честность: **добавьте в таблицу ещё одну свежую строку по другому
направлению и мысленно прогоните запрос.** Если ответ по вашему направлению
изменился — свежесть считается по таблице, а не по группе.
