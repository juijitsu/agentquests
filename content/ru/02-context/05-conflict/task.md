# Бумаги · Двадцать четыре или двадцать шесть и четыре

Груз TX-118 подходит к мосту, который держит двадцать шесть тонн.

Накладная 4471: двадцать четыре тонны. Весовая в Ларедо: двадцать шесть и
четыре. Оба документа сегодняшние, оба настоящие.

Агент отвечает: пройдёт.

```
python engine/check.py content/ru/02-context/05-conflict/starter/novice/agent.py
```

Посмотрите на первую строку проверки: до модели дошло одно значение веса из
двух. Второе не потерялось по дороге и не выпало из окна — его затёрло словарём
при сборке, потому что у словаря на ключ приходится одно значение.

**Донесите оба показания вместе с источниками.**

Выбирать, какому документу верить, — не ваша работа. В данных ответа нет, и
задача агента об этом сказать.

## Сдано, если

- до модели дошли оба значения веса;
- в ответе сказано, что источники расходятся;
- названы оба источника — иначе непонятно, кому звонить;
- обращений к модели не больше двух.
