# Метод · Одна сборка, пять условий

Весь сборщик — один цикл по отсортированному списку. Разница между рабочим и
нерабочим — в четырёх строчках внутри.

**Сортируйте по отдаче, а не по порядку и не по цене.**

```python
ranked = sorted(blocks, key=lambda b: model.worth(b) / b["cost"], reverse=True)
```

**Пропускайте, а не обрывайте.** Дорогой блок в середине не должен заканчивать
набор — после него идут дешёвые, которые ещё поместятся:

```python
if spent + block["cost"] > BUDGET:
    continue
```

**Кладите блок целиком, с ролью и источником.**

```python
{"role": "data", "id": ..., "source": ..., "text": ..., "cost": ...}
```

Роль — как читать. Источник — кому звонить. Стоимость — чтобы бюджет можно было
проверить не на слово.

**Ничего не схлопывайте и ничего не выбрасывайте.** Два показания веса едут как
два блока. Подложенная бумага едет как данные. Решать, чему верить и что делать
с попыткой, будут выше.

---

Проверка на честность, одна на все пять: **пройдитесь по брифу и для каждого
блока скажите, почему он здесь и почему в этой форме.** Если про какой-то блок
ответ «остался с прошлой сортировки» или «а куда его девать» — вы собрали не
бриф, а остаток бюджета.
