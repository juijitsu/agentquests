# Оценка · Пять из восьми, четыре из них знакомы

Агент прогнал набор: пять из восьми. Шестьдесят три процента.

Четыре случая из этих восьми дословно лежат в промпте агента как примеры. На
них он не отвечает, а вспоминает, и все четыре, разумеется, верны.

```
python engine/check.py content/ru/04-evaluation/05-leak/starter/novice/agent.py
```

Посмотрите на первую строку проверки: на утечку не проверен ни один случай.

Честный счёт — по тем четырём, которых в промпте нет: **один из четырёх**.
Двадцать пять процентов вместо шестидесяти трёх. Это не погрешность, это
разница между «работает» и «не работает».

**Посчитайте отдельно счёт по незнакомым случаям.**

## Сдано, если

- на утечку проверены все восемь случаев;
- назван честный счёт по незнакомым: один из четырёх;
- общий счёт тоже назван — разрыв между ними полезен;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | счёт по всему набору, в `TODO` назван нужный инструмент |
| `starter/advanced/` | сказано только, что всё прежнее сделано верно |
| `starter/pro/` | контракт и природа утечки |

## Если застряли

Проверять надо каждый случай, а не подозрительные: подозрительными окажутся
не те.
