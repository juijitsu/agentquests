# Метод · Отделить знакомое от незнакомого

**Шаг 1. Прогоните набор целиком.** Общий счёт нужен: по нему видно, насколько
система опирается на память.

**Шаг 2. Спросите про каждый случай, не лежит ли он в промпте.**

```python
clean = [c for c in CASES if not run_tool("in_prompt", {"case": c["id"]})]
```

Про **каждый**, а не про подозрительные: подозрительными окажутся не те.

**Шаг 3. Посчитайте счёт отдельно по незнакомым.**

```python
clean_passed = [c for c in clean if c in passed]
```

**Шаг 4. Покажите оба числа.** Не заменяйте одно другим: разрыв между ними и
есть полезная величина.

---

Проверка на честность: **возьмите промпт агента и поищите в нём тексты случаев
из набора.** Если нашли хоть один — счёт, который вы показывали вчера, был
завышен, и надо посчитать заново.
