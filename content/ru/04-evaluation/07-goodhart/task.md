# Оценка · Сто процентов конкретности

Уклончивость победили. Было пятьдесят процентов конкретных ответов, стало сто.

Три из этих конкретных ответов выдуманы:

```
c6  ожидалось: нет данных   ответ: 3.15
c7  ожидалось: нет данных   ответ: 22 т
c8  ожидалось: нет данных   ответ: 19:30
```

```
python engine/check.py content/ru/04-evaluation/07-goodhart/starter/novice/agent.py
```

Посмотрите на первую строку проверки: с целью не сверялось ничего. Считалась
только метрика — доля конкретных ответов, — а она выросла вдвое.

Старая версия на этих случаях говорила «нет данных». По метрике это
уклончивость, за которую её и ругали. По существу — единственно верное
поведение: данных действительно нет.

**Посчитайте рядом цену метрики: ответы конкретные и при этом неверные.**

## Сдано, если

- каждый ответ обеих версий сверен с целью;
- названо число уверенных ошибок у новой версии — три;
- метрика тоже названа: пятьдесят против ста;
- обращений к модели не больше двух.

## Если застряли

Вред считается не по всем ошибкам, а по конкретным. «Не уверен» на вопрос без
ответа не даст правильного числа и не даст неправильного; «3.15» даст
неправильное, и его используют.
