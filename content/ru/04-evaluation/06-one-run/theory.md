# Теория · Пять из шести, но какие пять

Набор чистый, утечки нет, судья независимый. Прогон даёт пять из шести.

Второй прогон того же набора той же системой даёт три из шести.

## Модель отвечает не всегда одинаково

Это не поломка и не случайность в данных. Языковая модель по устройству
недетерминирована: одинаковый запрос может дать разные ответы, и чем сложнее
случай, тем чаще расходятся.

Внутри набора это выглядит так:

```
c1  ✓ ✓ ✓ ✓ ✓     держится всегда
c2  ✓ ✓ ✓ ✓ ✓
c3  ✓ ✓ ✓ ✓ ✓
c4  ✗ ✗ ✗ ✗ ✗     не работает никогда
c5  ✓ ✗ ✓ ✗ ✓     через раз
c6  ✓ ✓ ✗ ✗ ✗     через раз
```

Три случая надёжны, один надёжно сломан, два **не надёжны ни в какую сторону**.

На нулевом прогоне оба неустойчивых выпали удачно. Отсюда и пять из шести.

## Одно число вместо трёх состояний

Главная ошибка здесь не в том, что счёт завышен. Она в том, что случаи разного
рода склеены в одно число.

У случая три состояния, а не два:

- **работает** — верно на всех прогонах;
- **не работает** — неверно на всех;
- **не держится** — то так, то эдак.

Третье состояние хуже второго. Сломанное чинят: оно видно, воспроизводится,
на него заводят задачу. Неустойчивое живёт годами: у одного разработчика
воспроизвелось, у другого нет, тикет закрывают как «не воспроизводится», а в
проде оно падает раз в три дня.

Меряя одним прогоном, вы **не различаете второе и третье** и потому не можете
даже узнать, что у вас есть проблема этого рода.

## Сколько прогонов

Столько, чтобы неустойчивость успела проявиться. Одного мало всегда, двух почти
всегда мало, пять уже кое-что показывают. Точное число зависит от того, насколько
редкими бывают срывы и насколько дорого стоит прогон.

Правило проще числа: **если случай ни разу не менял вердикт, вы прогнали
недостаточно раз, чтобы это утверждать.**

## Что показывать

Не среднюю долю. «Случай c5 верен в шестидесяти процентах прогонов» звучит
научно и не помогает: решение по нему всё равно бинарное — можно ли на нём
строить.

Полезнее список: что держится, что нет. **Неустойчивые случаи — отдельная
строка отчёта**, потому что и работа с ними отдельная.
