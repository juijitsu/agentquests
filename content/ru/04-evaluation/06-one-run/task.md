# Оценка · Пять из шести на удачном прогоне

Агент прогнал набор один раз: пять из шести.

Второй прогон того же набора той же системой даёт три из шести.

```
python engine/check.py content/ru/04-evaluation/06-one-run/starter/novice/agent.py
```

Посмотрите на первую строку проверки: прогонов на случай — один.

Два случая из шести отвечают через раз. На нулевом прогоне оба выпали удачно,
и агент объявил систему рабочей. На третьем прогоне оба выпали неудачно.

**Прогоните каждый случай несколько раз и разделите на три состояния:**
держится всегда, не работает никогда, не держится.

## Сдано, если

- каждый случай прогнан все пять раз;
- неустойчивые случаи названы поимённо;
- в отчёте три устойчиво верных из шести;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | один прогон, в `TODO` описано разделение на три |
| `starter/advanced/` | сказано только, что всё прежнее сделано верно |
| `starter/pro/` | контракт и природа недетерминированности |

## Если застряли

Порядок проверок решает: `all` строже `any`, поэтому идёт первым. Начав с
`any`, вы запишете в неустойчивые и те случаи, что верны всегда.
