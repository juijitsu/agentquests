# Метод · Прогнать несколько раз, разделить на три

**Шаг 1. Перебирайте прогоны внутри случая.**

```python
results = [
    run_tool("check", {"case": case["id"], "run": n}) == "верно"
    for n in range(RUNS)
]
```

Внешний цикл по случаям, внутренний по прогонам, а не наоборот: вам нужна
история каждого случая, а не срез каждого прогона.

**Шаг 2. Разложите на три состояния.**

```python
if all(results):
    stable_ok.append(...)
elif any(results):
    flaky.append(...)
```

Порядок проверок важен: `all` строже, поэтому идёт первым. Начав с `any`, вы
запишете в неустойчивые и те, что всегда верны.

**Шаг 3. Не усредняйте.** Доля успешных прогонов — красивое число, по которому
нельзя принять решение. Список неустойчивых случаев — некрасивое, по которому
можно.

**Шаг 4. Не выбрасывайте неустойчивые в провалы.** Это разные состояния и
разная работа: сломанное чинят по воспроизведению, неустойчивое сперва ловят.

---

Проверка на честность: **прогоните набор дважды и сравните отчёты.** Если они
отличаются, ваше измерение само неустойчиво, и любое сравнение версий по нему
бессмысленно.
