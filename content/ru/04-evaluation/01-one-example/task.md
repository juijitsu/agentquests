# Оценка · Починили один, сломали два

Агента поправили: старая версия не знала про топливную надбавку, новая знает.

Агент-оценщик проверяет этот случай и рапортует: стало лучше.

```
python engine/check.py content/ru/04-evaluation/01-one-example/starter/novice/agent.py
```

Посмотрите на первую строку проверки: прогнан один случай из шести. Тот самый,
ради которого правку и делали, — он обязан был пройти.

Остальные пять никто не спросил. А новая версия называет позапрошлогоднюю
ставку и путает вес по накладной.

**Прогоните обе версии по всему набору и сравните числа.**

## Сдано, если

- на каждой версии прогнаны все шесть случаев;
- вердикт — что стало хуже;
- в ответе назван счёт: 5 из 6 против 4 из 6;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | проверка одного случая, в `TODO` описан нужный прогон |
| `starter/advanced/` | сказано только, ради чего делалась правка |
| `starter/pro/` | контракт и устройство набора |

## Если застряли

Обе версии обязаны пройти **один и тот же** набор. Сравнение старой на одних
случаях с новой на других даёт число, не значащее ничего.
