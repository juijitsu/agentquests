# Метод · Набор, обе версии, счёт

**Шаг 1. Возьмите набор целиком.** Не первый случай, не любимый, не тот, ради
которого правили. Все.

```python
for c in CASES:
```

**Шаг 2. Прогоните обе версии по одному и тому же набору.**

```python
for version in ("old", "new"):
```

Порядок циклов неважен, важно, что внешний перебирает версии, а внутренний —
случаи, и второй одинаков для обеих.

**Шаг 3. Считайте совпадения.**

```python
run_tool("ask", {"version": version, "case": c["id"]}) == c["expected"]
```

**Шаг 4. Сравнивайте числа, а не впечатления.** «Кажется, стало лучше» — не
результат измерения. Результат измерения — два числа и разница между ними.

---

Проверка на честность: **уберите из набора тот случай, ради которого делалась
правка, и посчитайте заново.** Если после этого правка выглядит провальной —
так и есть, и вы только что узнали то, чего не знали.
