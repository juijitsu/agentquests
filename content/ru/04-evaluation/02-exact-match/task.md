# Оценка · Откатить улучшение

Новая версия отвечает верно на все шесть случаев. Старая ошибалась на одном.

Оценщик показывает: старая пять из шести, новая три из шести. Стало хуже,
правку откатить.

```
python engine/check.py content/ru/04-evaluation/02-exact-match/starter/novice/agent.py
```

Посмотрите на первую строку проверки: сверок по смыслу ноль. Ответы сравнивались
посимвольно, и три верных ответа объявлены ошибками:

```
ожидалось: 2.90    получено: 2 доллара 90 центов
ожидалось: 18:00   получено: до шести вечера
ожидалось: 24 т    получено: двадцать четыре тонны
```

**Сверяйте ответ, а не его запись.**

## Сдано, если

- каждый ответ обеих версий сверен по смыслу;
- вердикт — что стало лучше;
- счёт новой версии назван: 6 из 6;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | посимвольное сравнение, в `TODO` назван нужный вызов |
| `starter/advanced/` | сказано только, что прогон сделан по всем правилам |
| `starter/pro/` | контракт и природа расхождения |

## Если застряли

Нормализация строк здесь не поможет. «2 доллара 90 центов» и «2.90» не имеют
общих букв — это не разное написание одного текста, а разные тексты об одном
факте.
