# Оценка · Девяносто процентов

Набор из двадцати случаев. Восемнадцать верных.

Оценщик показывает: девяносто процентов.

```
python engine/check.py content/ru/04-evaluation/03-average/starter/novice/agent.py
```

Посмотрите на первую строку проверки: по видам не посчитано ничего. А в наборе
их три, и они несравнимы.

Ставки: шесть из шести. Расписание: шесть из шести. Перегруз: **четыре из
восьми**. Половина ответов про перегруз неверна, и каждая такая ошибка ставит
гружёный тягач на мост, который его не держит.

Двенадцать безупречных случаев из двух лёгких видов вытянули среднее наверх.

**Считайте долю внутри каждого вида.**

## Сдано, если

- посчитаны все три вида;
- слабое место названо;
- доля по перегрузу названа — пятьдесят процентов;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | один общий процент, в `TODO` описана разбивка |
| `starter/advanced/` | сказано только, что результат хороший |
| `starter/pro/` | контракт и намёк на устройство набора |

## Если застряли

Знаменатель — размер вида, а не размер набора. В этом вся разница между
«половина перегрузов неверна» и «перегрузы дают двадцать процентов ошибок».
