# Оценка · Финал трека

Никаких новых приёмов. Ново лишь то, что все пять работают одновременно, и по
итогу принимается настоящее решение: выкатывать новую версию или нет.

Беглый отчёт — один прогон, самооценка, одно число — показывает девять из
девяти. Сто процентов.

```
python engine/check.py content/ru/04-evaluation/08-boss/starter/novice/agent.py
```

Заготовка нарушает все пять условий, и проверка показывает это построчно.
Чините по одному — каждая строка вердикта относится к своему уровню трека.

Честный отчёт даёт ноль процентов по перегрузу и два неустойчивых случая.
Один из трёх случаев перегруза лежал в промпте — исключите его, и от вида
останутся сломанный и неустойчивый. Каждая ошибка там ставит гружёный тягач на
мост, который его не держит.

## Сдано, если

- судил независимый судья;
- на утечку проверены все девять случаев;
- каждый случай прогнан три раза;
- в отчёте назван слабый вид с его долей;
- решение — выкатывать нельзя;
- обращений к модели не больше двух.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | пять `TODO` с номерами уровней, откуда навык |
| `starter/advanced/` | список пяти условий и отчёт, нарушающий все |
| `starter/pro/` | контракт и критерий приёмки |

## После этого уровня

Трек «Оценка» закончен. Вы умеете измерять систему так, чтобы измерению можно
было верить: набором, а не примером; по смыслу, а не по буквам; независимым
судьёй по записанной заранее рубрике; на данных, которых система не видела; за
несколько прогонов; в разбивке по цене ошибки; и с парной метрикой, которая
портится при перекручивании основной.

Дальше — трек «Красная команда»: как ломать то, что вы построили, прежде чем
это сделает кто-то другой.
