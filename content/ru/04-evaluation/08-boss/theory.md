# Теория · Выкатывать или нет

Семь уровней разбирали по одной поломке измерения. Здесь их пять сразу, и
решение по итогу принимается настоящее: выкатывать новую версию или нет.

## Что показывает беглый отчёт

Один прогон, самооценка, одно число: **девять из девяти**. Сто процентов.
Выкатываем.

Теперь по-честному.

| Что нужно | Откуда навык | Что скрывает поблажка |
|---|---|---|
| Независимый судья | уровень 04 | автор засчитывает себе всё |
| Исключить утечку | уровень 05 | два случая лежат в промпте |
| Несколько прогонов | уровень 06 | сломанное неотличимо от неустойчивого |
| Разбивка по видам | уровень 03 | лёгкие виды вытягивают среднее |
| Устойчивость в счёте | уровень 06 | верный через раз засчитан как верный |

Итог после всех пяти:

```
ставки       100%
расписание    67%
перегруз       0%      ← слабое место
неустойчивых 2: s3, w3
```

Ноль процентов на перегрузе. Из двух оставшихся случаев один не работает
никогда, второй через раз. Каждая ошибка там ставит гружёный тягач на мост,
который его не держит.

## Поблажки складываются в одну сторону

Вот главное наблюдение уровня, и оно неочевидно.

Каждая из пяти поблажек по отдельности выглядит мелочью. Ну посудил автор.
Ну прогнали один раз. Ну не разбили по видам. Каждая добавляет по несколько
процентов.

Но **все они смещают результат вверх**. Ни одна не занижает.

Это не совпадение: поблажки берутся оттуда, где проверять дороже, а проверять
дороже там, где система работает хуже. Автор мягче к себе. Один прогон удобнее
пяти. Общее число приятнее разбивки, в которой видно провал.

Оттого сто процентов превращаются не в девяносто, а в ноль по тому виду,
который важнее прочих.

## Порядок в отчёте

Он не произволен.

**Утечка исключается первой**, до всего остального: считать прогоны и виды по
случаям, ответ на которые лежит в промпте, — работа впустую.

**Прогоны идут раньше устойчивости**, потому что устойчивость определяется по
нескольким прогонам, а не наоборот.

**Судья вызывается на каждый прогон**, а не на случай: у случая нет одного
ответа, у него их RUNS.

**Разбивка последняя**, потому что она группирует уже посчитанное.

## Решение принимает правило, а не человек

Обратите внимание на последнюю строку отчёта: решение выводится из чисел
механически — ниже планки хоть один вид или есть хоть один неустойчивый случай,
значит выкатывать нельзя.

Это важно ровно по той же причине, по которой рубрику пишут до просмотра
ответов. **Правило, сформулированное после того, как увидели числа,
подстраивается под желаемое решение** — и всегда в сторону «выкатываем, там
почти хорошо».
