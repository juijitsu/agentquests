# Метод · Пять шагов в одном порядке

**Шаг 1. Исключите утечку.**

```python
clean = [c for c in CASES if not run_tool("in_prompt", {"case": c["id"]})]
```

Проверяются все случаи, а не подозрительные. Исключаются из счёта, а не из
набора видов.

**Шаг 2. Прогоните каждый оставшийся случай несколько раз, судя независимо.**

```python
results = [
    model.judge_blind(RUBRIC, run_tool("answer", {"case": case["id"], "run": n}))
    for n in range(RUNS)
]
```

Судья вызывается на каждый прогон: ответов у случая столько же, сколько
прогонов.

**Шаг 3. Разложите на устойчивые и неустойчивые.** `all` перед `any`, иначе
верные всегда попадут в неустойчивые.

**Шаг 4. Считайте долю внутри вида.** Знаменатель — размер вида после
исключения утечки.

**Шаг 5. Отдайте решение правилу.** Планка и условие про неустойчивость
записаны заранее; ваше дело — посчитать, а не решить.

---

Проверка на честность: **уберите по очереди каждый из пяти шагов и посмотрите,
куда поедет число.** Оно поедет вверх во всех пяти случаях — и в этом всё дело.
