# Задание · Замкнуть цепочку

В `agent.py` цикл написан целиком и почти работает. Одна связь разорвана:
результат инструмента никуда не попадает.

Запустите как есть — увидите, что произойдёт:

```
python engine/check.py content/ru/00-foundations/01-what-is-an-agent/starter/novice/agent.py
```

Модель просит статус груза, код его получает — и выбрасывает. На следующей
итерации модель снова не видит результата и просит снова. И так до потолка.

**Почините так, чтобы результат инструмента попадал в историю сообщений.**

## Сдано, если

- агент возвращает строку со статусом груза;
- уложился в 3 итерации;
- процесс не упал.

## Три сложности

Выберите папку под свой уровень — условие сдачи у всех одинаковое:

| Папка | Что дано |
|---|---|
| `starter/novice/` | рабочий код, одна строка помечена `TODO` |
| `starter/advanced/` | цикл есть, блок выполнения инструментов надо дописать |
| `starter/pro/` | пустая функция и условие |

## Подсказка, если застряли

Посмотрите, что делает `messages.append` в предыдущих строках, и какая роль
у сообщения с результатом инструмента. Ролей всего три: `user`, `assistant`, `tool`.
