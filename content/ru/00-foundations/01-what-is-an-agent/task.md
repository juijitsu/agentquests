# Смена 1 · Диспетчер молчит

Клиент третий раз спрашивает, где его груз. Диспетчер, которого вам передали,
крутится и не отвечает.

Запустите как есть:

```
python engine/check.py content/ru/00-foundations/01-what-is-an-agent/starter/novice/agent.py
```

Посмотрите на лог. Один и тот же инструмент вызывается десять раз подряд с
одним и тем же результатом. Модель будто не замечает, что ответ уже получен.

Она и не замечает.

**Почините так, чтобы результат инструмента попадал в историю сообщений.**

## Сдано, если

- агент возвращает статус груза;
- уложился в 3 итерации;
- процесс не упал.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | рабочий код, одна строка помечена `TODO` |
| `starter/advanced/` | цикл есть, блок выполнения инструментов надо дописать |
| `starter/pro/` | пустая функция и условие |
