# Метод · Как читать агентный цикл

Процедура на четыре шага. Работает с любым агентным кодом, своим и чужим.

**Шаг 1. Найдите цикл.** Ищите `while` или `for` вокруг вызова модели. Всё, что
внутри — одна итерация разговора.

**Шаг 2. Найдите условие выхода.** Обычно `if not response.tool_calls`. Нет
условия выхода — код зациклится.

**Шаг 3. Найдите ограничитель.** Счётчик итераций с потолком. Без него любая
ошибка превращается в бесконечный цикл, который молча жжёт деньги.

**Шаг 4. Проследите путь одного результата.** Возьмите один вызов инструмента и
пройдите глазами: модель попросила → код выполнил → результат попал в `messages`
→ модель увидела его на следующей итерации. **Разрыв в этой цепочке — самая
частая поломка.**
