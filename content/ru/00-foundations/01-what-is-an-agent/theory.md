# Теория · Что вообще происходит

Слово «агент» звучит так, будто внутри спрятано что-то сложное. Внутри спрятан
цикл `while`, и это не упрощение — это буквально всё.

У любого агента ровно три части.

**Модель** — то, что выбирает следующий шаг. Она ничего не выполняет сама и
ничего не помнит между вызовами.

**Инструменты** — обычные функции вашего кода. Посмотреть статус груза, посчитать
стоимость, отправить письмо. Модель их не запускает, она только просит запустить.

**Цикл** — ваш код, который связывает первое со вторым. Спросил модель, получил
просьбу вызвать инструмент, вызвал, положил результат обратно, спросил снова.
Так до тех пор, пока модель не скажет: «всё, вот ответ».

Вот он целиком:

```python
messages = [{"role": "user", "content": "Где груз TX-4471?"}]

while True:
    response = model.call(messages, tools=TOOLS)
    messages.append({"role": "assistant", ...})

    if not response.tool_calls:
        return response.text                 # закончил

    for call in response.tool_calls:
        result = run_tool(call.name, call.arguments)
        messages.append({"role": "tool", "content": result})
```

Двенадцать строк. Что бы вам ни показали дальше — LangGraph, OpenAI Agents SDK,
чей-то фреймворк на тысячу строк — внутри всегда это.

Обратите внимание на список `messages`. Он растёт на каждой итерации, и в нём
лежит всё, что агент знает о происходящем: вопрос пользователя, просьба вызвать
инструмент, результат вызова. Модель на каждом шаге видит этот список целиком и
ничего кроме него.

Отсюда следует вещь, которая объясняет половину будущих багов: **если что-то не
попало в `messages`, для модели этого не существует.**
