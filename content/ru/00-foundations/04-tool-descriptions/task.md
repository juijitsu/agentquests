# Смена 4 · Ответ не на тот вопрос

Клиент спросил, сколько ждать на переходе Хоргос. Диспетчер прислал ему счёт за
перевозку.

```
python engine/check.py content/ru/00-foundations/04-tool-descriptions/starter/novice/agent.py
```

Первая строка проверки покажет, какой инструмент был вызван. Логика цикла в
порядке — вы её починили на прошлых уровнях. Сломано описание.

**Перепишите описание так, чтобы агент выбрал верный инструмент.**

Код трогать не нужно вовсе. Правка целиком в тексте.

## Сдано, если

- вызван `check_border_status` и только он;
- в ответе есть очередь на переходе;
- уложился в 3 итерации.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | одно описание испорчено, второе целое — есть с чем сравнить |
| `starter/advanced/` | оба описания пусты, писать с нуля |
| `starter/pro/` | список инструментов пуст, объявить оба самому |

## Если застряли

Прочитайте описание соседнего инструмента и найдите в нём слово из вопроса
клиента. Теперь понятно, почему выбрали его.
