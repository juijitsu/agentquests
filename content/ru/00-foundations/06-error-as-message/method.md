# Метод · Вернуть ошибку в цикл

Четыре шага. Та же процедура работает для любого инструмента.

**Шаг 1. Решите, кому адресован отказ.** Задайте один вопрос: может ли модель
это исправить, изменив аргументы? Да — отказ для модели. Нет — для человека.

**Шаг 2. Перехватите исключение у места вызова.** Не внутри инструмента и не
снаружи цикла, а ровно там, где вы его вызываете:

```python
try:
    result = run_tool(call.name, call.arguments)
except ValueError as exc:
    result = str(exc)
```

Ошибка перестала быть исключением и стала обычным результатом.

**Шаг 3. Положите её в историю той же ролью.** Роль `tool`, как у успешного
результата. Для модели это просто ещё один ответ инструмента — она не различает
удачные и неудачные, она читает текст.

**Шаг 4. Продолжите цикл.** Ничего не прерывайте. Следующая итерация — это и
есть попытка исправления.

---

Проверка себя: посчитайте, сколько разных значений агент попробовал. Если одно —
самоисправления не было, что бы ни отвечал агент в итоге.
