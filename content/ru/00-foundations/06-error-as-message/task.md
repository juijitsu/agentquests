# Смена 6 · Loredo вместо Laredoа

В заявке опечатка: клиент написал «Loredo». Такого перехода нет — есть Laredo.
Диспетчер сообщил об этом клиенту и на этом остановился.

```
python engine/check.py content/ru/00-foundations/06-error-as-message/starter/novice/agent.py
```

Обратите внимание на первую строку проверки: агент попробовал **одно** значение.
Он не падал, не зацикливался, вежливо ответил — и сдался там, где мог исправиться
сам за один шаг.

Текст ошибки, которую он получил, содержит список допустимых переходов. Модель
его не увидела.

**Сделайте так, чтобы ошибка инструмента дошла до модели.**

## Сдано, если

- агент попробовал не меньше двух значений;
- в ответе есть очередь на переходе;
- уложился в 3 итерации.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | исключение ловится, но уходит не туда — строка помечена `TODO` |
| `starter/advanced/` | исключение не ловится вовсе |
| `starter/pro/` | контракт и условие |
