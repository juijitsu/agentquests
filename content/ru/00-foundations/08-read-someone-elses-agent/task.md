# Финал · Пятница, сдача заказчику

Разработчик уволился. Агент уходит заказчику в пятницу. Из пяти обращений
проходит не всё, и никто не знает почему.

```
python engine/check.py content/ru/00-foundations/08-read-someone-elses-agent/starter/novice/agent.py
```

Проверка покажет счёт и первые провалившиеся обращения.

**Найдите и устраните все дефекты, чтобы прошли все пять обращений.**

Их три. Каждый вы уже видели по отдельности на прошлых уровнях.

## Сдано, если

- проходят все пять обращений.

## Выберите сложность

На этом уровне у всех одинаковый файл — задача диагностическая, вычитать нечего.
Убывают подсказки:

| Папка | Что сказано |
|---|---|
| `starter/novice/` | три места помечены комментариями |
| `starter/advanced/` | дефектов три, где — не сказано |
| `starter/pro/` | ничего, кроме того, что проходит не всё |

## Если застряли

Запустите и посмотрите, сколько обращений провалилось. Если почти все — ищите
общее место, через которое проходит каждый запрос.
