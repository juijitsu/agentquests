# Метод · Разбор чужого агента

Четыре шага. Тот же порядок работает для любого незнакомого агентного кода.

**Шаг 1. Запустите, не читая.** Получите список провалов. Пять строк вывода
скажут больше, чем пятнадцать минут чтения.

**Шаг 2. Сгруппируйте провалы.** Одна причина обычно ломает несколько
обращений. Если провалилось четыре из пяти — это скорее один дефект в общем
месте, чем четыре разных.

**Шаг 3. Идите от симптома к месту.** По таблице симптомов из теории. Каждый
указывает на конкретную область: цикл, разбор ответа, описания, обработку
ошибок.

**Шаг 4. Чините по одному и перезапускайте.** Не правьте три места сразу —
иначе не поймёте, что из этого помогло, а что сломало ещё что-нибудь.

---

Начинайте с того дефекта, который ломает больше всего обращений: он обычно
самый общий и после него картина проясняется.
