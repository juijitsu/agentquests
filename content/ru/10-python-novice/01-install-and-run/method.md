# Метод · Как это набрать, по шагам

Здесь не объяснения, а действия. Теория выше, если что-то непонятно —
вернитесь туда.

---

## Шаг 1. Откройте решение

Кнопка **«Решать этот уровень»** внизу страницы. Откроется терминал с уже
готовой заготовкой — писать с чистого листа не надо.

Слева от кнопки «Запустить» три сложности. Начните с **«Новичок»**: там в
коде стоит `TODO`, и в нём написано, что именно набрать.

---

## Шаг 2. Посмотрите, что уже написано

В заготовке лежит вот это:

```python
def solve(name: str) -> str:
    # TODO: ...
    return "Привет!"
```

Функция работает. Она запускается, ничего не ломает и возвращает текст.
Просто текст не тот: имени в нём нет.

Убедитесь сами — нажмите **«Запустить»** прямо сейчас, не меняя ничего.
Увидите:

```
✓ вернулся текст: да
✗ совпало имён: 0 из 5
✗ первое расхождение: на имени «Мария»
    ждали:    Привет, Мария!
    получили: Привет!
                    ^
```

Первая строка зелёная: тип правильный, вернулся текст. Вторая красная: ни
одно имя не сошлось. Третья показывает первое расхождение и стрелкой —
место, с которого строки разошлись.

**Так и надо начинать любой уровень: запустить заготовку как есть.** Она
сама скажет, чего не хватает.

---

## Шаг 3. Замените строку возврата

Нужно превратить

```python
    return "Привет!"
```

в

```python
    return "Привет, " + name + "!"
```

Набирается это так, по частям:

1. Сотрите всё после `return`, оставив сам `return` и пробел после него.
2. Наберите кавычку `"` — редактор сам поставит вторую, закрывающую.
3. Внутри кавычек наберите: `Привет`, потом запятую, потом **пробел**.
   Должно получиться `"Привет, "` — пробел стоит перед закрывающей кавычкой,
   он часть текста.
4. Поставьте курсор **за** закрывающей кавычкой.
5. Наберите пробел, `+`, пробел.
6. Наберите `name` — **без кавычек**. Это ярлык, а не текст.
7. Наберите пробел, `+`, пробел.
8. Наберите кавычку, внутри `!`, и выйдите за закрывающую кавычку.

Итог строки целиком:

```python
    return "Привет, " + name + "!"
```

Четыре пробела в начале обязательны. Они уже стоят в заготовке — не сотрите
их.

---

## Шаг 4. Запустите

Кнопка **«Запустить»** или `Ctrl+Enter`.

Если всё верно:

```
✓ вернулся текст: да
✓ совпало имён: 5 из 5
✓ первое расхождение: все совпали

PASS  следующий уровень открыт
```

---

## Шаг 5. Если не сошлось

Вердикт всегда говорит, что именно не так. Три типовых случая:

**Строки почти одинаковые, но не совпали.** Смотрите на стрелку. Она стоит
ровно под первым символом, который разошёлся. Чаще всего это пропущенный или
лишний пробел после запятой.

```
ждали:    Привет, Мария!
получили: Привет,Мария!
                 ^ здесь не хватает пробела
```

**Одна и та же строка на всех именах.** Значит имя вписано в текст, а ярлык
`name` не используется. Вернитесь к шагу 3.

**Вместо вердикта — название ошибки.** Программа не запустилась. Под ошибкой
будет объяснение по-русски: что случилось и что чинить. Частые случаи:

- `IndentationError` — стёрли четыре пробела в начале строки;
- `SyntaxError` — не закрыли кавычку или скобку;
- `NameError` — написали текст без кавычек.

---

## Шаг 6. Проверьте, что поняли

Не обязательный шаг, но полезный. Подставьте эталон кнопкой **«Подставить
эталон»**, посмотрите на него, потом нажмите **«Вернуть заготовку»** и
наберите то же самое сами, не подглядывая.

Если получилось с первого раза — уровень усвоен. Если нет — вы только что
нашли место, которое стоит перечитать.

## Как запускать у себя

Понадобится, только если поставили питон на свою машину. Скачайте
репозиторий и из его корня выполните:

```
python engine/check.py content/ru/10-python-novice/01-install-and-run/starter/novice/agent.py
```

Это ровно то же самое, что делает кнопка на странице: тот же движок, тот же
вердикт.
