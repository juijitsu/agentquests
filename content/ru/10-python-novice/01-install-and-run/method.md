# Метод · Правка, запуск, чтение

**Шаг 1. Откройте решение.** Кнопка «Решать этот уровень» открывает страницу
с терминалом. Заготовка там уже лежит, писать с чистого листа не надо.

**Шаг 2. Правьте тело функции.** Всё, что ниже строки `def solve(name):` и
сдвинуто вправо, — это тело. Сдвиг обязателен: питон по нему понимает, где
функция начинается и где кончается. Четыре пробела, не таб.

**Шаг 3. Запустите.** Кнопка «Запустить» или `Ctrl+Enter`.

**Шаг 4. Прочитайте вердикт.** Три строки:

```
вернулся текст: да
совпало имён: 3 из 5
первое расхождение: на имени «Анна-Мария» ждали ..., получили ...
```

Первая строка про тип: если там «нет», значит функция вернула не текст —
чаще всего потому, что в ней `print` вместо `return`, и тогда возвращается
пустота.

Вторая говорит, сколько имён сошлось. Третья показывает первое несовпадение
целиком: что подали, что ждали, что получили. Этого хватает, чтобы понять
ошибку, не гадая.

**Шаг 5. Если программа упала.** Вердикта не будет, вместо него — название
ошибки и объяснение по-русски. Самые частые на этом уровне: забыли закрыть
кавычку, забыли двоеточие после `def`, не сдвинули тело вправо.
