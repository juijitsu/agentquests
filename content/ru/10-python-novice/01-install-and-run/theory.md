# Теория · Первая программа, разобранная по буквам

Этот уровень объясняет **всё**, что понадобится для задания: что такое
функция, что такое параметр, зачем кавычки, как склеивать текст, что такое
отступ и чем `return` отличается от `print`. Ничего из этого не считается
известным заранее.

Читать целиком не обязательно подряд: если что-то уже знакомо, пролистывайте.

---

## Ставить ничего не нужно, чтобы начать

На странице решения есть терминал, и питон в нём уже работает — он
загружается прямо в браузер. Нажмите «Решать этот уровень», правьте код,
запускайте. Ничего скачивать не надо.

Это не тренажёр вместо настоящего языка. Это настоящий питон, собранный для
браузера: тот же синтаксис, те же ошибки, те же сообщения.

Установка на свою машину разобрана [в конце этого урока](#установка-на-свою-машину).
Она понадобится позже, когда захочется писать свои программы, а не решать
задачи курса.

---

## Что такое программа

Программа получает что-то на вход и отдаёт что-то на выход. Всё остальное —
подробности.

```
вход  ──▶  программа  ──▶  выход
```

В этом курсе каждое задание устроено одинаково: есть функция, ей передают
вход, она обязана вернуть выход. Здесь вход — имя человека, выход —
приветствие для него.

---

## Функция, по частям

Вот вся конструкция целиком. Ниже разобрана каждая её часть.

```python
def solve(name: str) -> str:
    return "Привет, " + name + "!"
```

### `def`

**Что это.** Ключевое слово. С него начинается объявление функции.

**Зачем.** Оно говорит питону: дальше идёт не просто код, а именованный
кусок кода, который можно будет вызвать.

**Что ломается.** Если написать `Def` или `DEF` — питон не поймёт. Язык
различает большие и маленькие буквы.

**Что вы увидите:** `SyntaxError: invalid syntax`.

### `solve` — имя функции

**Что это.** Название, по которому функцию находят и вызывают.

**Зачем.** Проверка ищет в вашем файле функцию именно с этим именем. Она не
догадается, что вы назвали её `resheniye` или `myFunc`.

**Чего не делать.** Не переименовывайте. Во всём курсе функция называется
`solve`.

**Что вы увидите, если переименуете:** «В файле нет функции solve».

### `(name: str)` — параметр

Это самая важная часть урока, и именно здесь спотыкаются чаще всего.

**Что это.** `name` — **ярлык**. Не имя человека, а имя ярлыка, который вы
навешиваете на то значение, что придёт снаружи.

**Зачем.** Ваша функция должна работать с **любым** именем. Проверка вызовет
её пять раз подряд:

```
solve("Мария")      →  внутри функции name указывает на "Мария"
solve("Иван")       →  внутри функции name указывает на "Иван"
solve("Ким")        →  внутри функции name указывает на "Ким"
```

Один и тот же код, каждый раз другое значение за ярлыком.

**Отсюда главный вывод:** вписать конкретное имя в ответ нельзя. Оно каждый
раз другое. В ответ надо положить **ярлык**, а питон сам подставит то, что
за ним лежит в этот раз.

**Чего не делать.** Не переименовывайте параметр в имя человека:

```python
def solve(Мария: str) -> str:      # ← так делать не надо
    return "Привет, Мария!"
```

Это законный питон, он не упадёт. Но функция теперь возвращает одну и ту же
строку для любого входа, и на втором же имени проверка скажет, что ждали
«Привет, Иван!», а получили «Привет, Мария!».

**Про `: str` и `-> str`.** Это подсказки для человека: «сюда придёт текст»,
«отсюда вернётся текст». Питон их не проверяет, программа работает и без
них. Оставьте как есть.

### Двоеточие в конце строки

**Что это.** Знак `:` после закрывающей скобки.

**Зачем.** Говорит: строка-заголовок кончилась, дальше идёт тело.

**Что ломается.** Забыли двоеточие — питон не понимает, где начинается тело.

**Что вы увидите:** `SyntaxError: expected ':'`.

### Отступ

**Что это.** Четыре пробела в начале строки тела.

**Зачем.** В большинстве языков тело обводят фигурными скобками. В питоне его
обозначают сдвигом вправо. Сдвинуто — значит внутри функции. Не сдвинуто —
значит снаружи.

```python
def solve(name: str) -> str:
    return "Привет, " + name + "!"
^^^^
четыре пробела, и это не украшение
```

**Что ломается.** Нет отступа — питон считает, что тело функции пустое.
Клавиша Tab тоже даёт отступ, но смешивать пробелы и табы в одном файле
нельзя, питон ругается отдельно.

**Что вы увидите:** `IndentationError: expected an indented block`.

### `return`

**Что это.** Ключевое слово, которое отдаёт значение обратно тому, кто вызвал
функцию.

**Зачем.** Проверка вызывает вашу функцию и смотрит, что она **вернула**.

**Чего не делать.** Не путайте с `print`. Об этом ниже отдельно, потому что
это вторая по частоте ошибка после параметра.

## Кавычки: текст против ярлыка

Второе место, где путаются.

**Что в кавычках — это буквы. Что без кавычек — это ярлык.**

```python
"Мария"     # шесть букв: М, а, р, и, я — и ничего больше
name        # ярлык; за ним лежит значение, пришедшее снаружи
"name"      # четыре буквы: n, a, m, e — а вовсе не значение
```

Сравните две строки:

```python
return "Привет, " + name + "!"     # правильно: ярлык без кавычек
return "Привет, name!"             # неправильно: вернётся слово «name»
```

Во второй строке `name` оказалось **внутри** кавычек, а значит перестало быть
ярлыком и стало четырьмя буквами.

**Что ломается, если убрать кавычки у текста.** Питон решит, что `Привет` —
это ярлык, и станет искать значение с таким именем. Не найдёт.

**Что вы увидите:** `NameError: name 'Привет' is not defined`.

**Как запомнить.** Кавычки — это забор. Внутри забора буквы лежат как есть,
питон в них не вмешивается. Снаружи забора всё, что похоже на слово, питон
считает именем чего-то.

## Склейка плюсом

**Что это.** Знак `+` между двумя текстами соединяет их в один.

```python
"а" + "б"           →  "аб"
"Привет, " + "Ким"  →  "Привет, Ким"
```

**Зачем здесь.** Приветствие собирается из трёх частей: текст до имени, само
имя и восклицательный знак.

```python
"Привет, "  +  name  +  "!"
└─ текст ─┘   └ярлык┘  └текст┘
```

**Про пробел.** Он должен быть **внутри кавычек**, после запятой:

```python
"Привет, "     ← правильно: запятая, пробел, закрывающая кавычка
"Привет,"      ← неправильно: получится «Привет,Мария!»
```

Пробелы между `+` и соседями на результат не влияют, они только для
читаемости. А вот пробел внутри кавычек — часть текста.

**Что ломается, если складывать текст с числом.** `"возраст: " + 30` не
работает: питон не знает, что делать с буквами и числом одновременно.

**Что вы увидите:** `TypeError: can only concatenate str (not "int") to str`.

Это понадобится на следующем уровне, здесь чисел нет.

## `return` против `print`

Две команды, которые новички путают, и путаница стоит дорого.

```python
print("Привет, " + name + "!")     # показать на экране
return "Привет, " + name + "!"     # отдать вызвавшему
```

**`print`** выводит значение на экран и на этом всё. Функция при этом не
возвращает **ничего**.

**`return`** отдаёт значение обратно. Проверка смотрит именно на него.

**Что вы увидите, если написать `print`:** первая строка вердикта скажет
«вернулся текст: нет». На экране при этом всё будет выглядеть правильно — и
это самое обидное.

**Как запомнить:** печать — для человека, возврат — для программы.

## Что будет, если ошибиться

Полный список того, что может пойти не так на этом уровне, и что делать.

| Что вы увидите | Что случилось | Что делать |
|---|---|---|
| `вернулся текст: нет` | написали `print` вместо `return` | замените `print(...)` на `return ...` |
| `совпало имён: 0 из 5`, а строки почти одинаковые | разница в одном символе | смотрите на стрелку под строками, она указывает точное место |
| одна и та же строка на всех именах | имя вписано в текст, ярлык не используется | верните `"Привет, " + name + "!"` |
| `IndentationError` | тело не сдвинуто вправо | поставьте четыре пробела в начале строки |
| `SyntaxError` | незакрытая кавычка, скобка или нет двоеточия | проверьте, что каждая кавычка и скобка закрыта |
| `NameError` | текст написан без кавычек | возьмите текст в кавычки |
| `AttributeError`, в тексте `solve` | функцию переименовали | верните имя `solve` |

Вердикт печатает эти объяснения сам, по-русски. Гадать не придётся.

---

## Чего не делать

- **Не переименовывать `solve`** — проверка ищет функцию по имени.
- **Не переименовывать `name`** — вернее, переименовать можно, но тогда и в
  теле надо использовать новое имя. Проще не трогать.
- **Не вписывать имя человека в ответ** — оно каждый раз другое.
- **Не писать `print` вместо `return`** — вернётся пустота.
- **Не смешивать табы и пробелы** — питон на это ругается отдельно.
- **Не писать код на русском** — ключевые слова английские: `def`, `return`.
  Русскими могут быть только тексты внутри кавычек и комментарии.

---

## Как это выглядит в настоящем коде

То же самое, только вход и выход сложнее:

```python
def rate_for(load: dict) -> float:
    return load["miles"] * 2.40
```

Та же форма: `def`, имя, параметр в скобках, двоеточие, отступ, `return`.
Отличается только то, что внутри. Всё, что вы разобрали на этом уровне,
работает и здесь.

## Установка на свою машину

Для решения задач курса не нужна. Понадобится, когда захочется писать свои
программы.

### Windows

1. Откройте **python.org**, раздел Downloads. Кнопка сама предложит версию
   под вашу систему.
2. Запустите скачанный файл. **Внизу первого окна поставьте галочку «Add
   python.exe to PATH».** Без неё система не будет знать, где лежит питон, и
   команда `python` не заработает.
3. Нажмите Install Now, дождитесь конца.
4. Откройте Терминал или PowerShell и наберите:

```
python --version
```

Должно ответить `Python 3.` и цифры. Если ответило «не является внутренней
или внешней командой» — галочку из шага 2 не поставили. Запустите установщик
снова, выберите Modify и добавьте питон в PATH.

### macOS

Питон в системе уже есть, но он старый и служебный, для работы не годится.
Ставьте свой: либо с **python.org**, обычным установщиком, либо через
Homebrew, если он у вас есть: `brew install python`.

Проверка в Терминале:

```
python3 --version
```

На macOS команда называется `python3`, а не `python`. Это нормально.

### Linux

Почти везде питон уже стоит. Проверьте:

```
python3 --version
```

Если не нашёлся: `sudo apt install python3` в Debian и Ubuntu,
`sudo dnf install python3` в Fedora, `sudo pacman -S python` в Arch.

### Чем писать код

Подойдёт любой текстовый редактор. Самый распространённый выбор —
**VS Code**: бесплатный, есть под все три системы.

Word и подобные **не подойдут**: они добавляют в файл невидимое оформление,
от которого питон ломается.
