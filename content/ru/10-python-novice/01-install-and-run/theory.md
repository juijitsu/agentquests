# Теория · Что такое программа и что надо поставить

Программа получает что-то на вход и отдаёт что-то на выход. Всё остальное —
детали.

В этом курсе каждая задача выглядит одинаково: есть функция, ей передают
вход, она обязана вернуть выход. На этом уровне вход — имя, выход —
приветствие. Дальше вход и выход будут сложнее, форма останется той же.

## Ставить ничего не обязательно

На странице решения есть терминал, и питон в нём уже работает: он загружается
прямо в браузер. Можно нажать «Решать», править код и запускать, ничего не
скачивая.

Это не учебный тренажёр вместо настоящего питона. Это настоящий питон,
собранный так, чтобы работать в браузере. Тот же язык, те же ошибки.

Но рано или поздно программу захочется запустить у себя, поэтому ниже —
установка.

## Windows

1. Откройте **python.org**, раздел Downloads. Кнопка сама предложит версию
   под вашу систему.
2. Запустите скачанный файл. **Внизу первого окна поставьте галочку «Add
   python.exe to PATH».** Без неё система не будет знать, где лежит питон,
   и команда `python` не заработает.
3. Нажмите Install Now и дождитесь конца.
4. Откройте Терминал или PowerShell и наберите:

```
python --version
```

Должно ответить `Python 3.` и дальше цифры. Если ответило «не является
внутренней или внешней командой» — галочку из шага 2 не поставили. Запустите
установщик снова, выберите Modify и добавьте питон в PATH.

## macOS

Питон в системе уже есть, но он старый и служебный, для работы он не годится.
Ставьте свой:

1. Либо с **python.org**, тот же раздел Downloads, обычный установщик.
2. Либо через Homebrew, если он у вас есть: `brew install python`.

Проверка в Терминале:

```
python3 --version
```

На macOS команда называется `python3`, а не `python`. Это нормально.

## Linux

Почти во всех дистрибутивах питон уже стоит. Проверьте:

```
python3 --version
```

Если не нашёлся, поставьте пакет: `sudo apt install python3` в Debian и
Ubuntu, `sudo dnf install python3` в Fedora, `sudo pacman -S python` в Arch.

## Чем писать код

Подойдёт любой текстовый редактор. Самый распространённый выбор —
**VS Code**, он бесплатный и есть под все три системы. Ставьте, если ничего
другого не привыкли использовать.

Word и подобные не подойдут: они добавляют в файл невидимое оформление, от
которого питон ломается.

## return, а не print

Две команды, которые новички путают, и путаница стоит дорого.

`print` показывает значение на экране и на этом всё. Вызвавший вашу функцию
не получает ничего.

`return` отдаёт значение обратно тому, кто вызвал. Проверка смотрит именно на
возвращённое, поэтому решение с `print` вместо `return` не сдаётся, даже если
на экране всё выглядит правильно.

Запомнить проще так: **печать это для человека, возврат это для программы.**
