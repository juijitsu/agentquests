# Первый запуск · Поздороваться

Файл называется `agent.py` — так его ищет проверка во всём курсе, менять имя
не надо. Внутри одна функция:

```python
def solve(name: str) -> str:
    ...
```

Ей передают имя, она обязана вернуть приветствие.

```
solve("Мария")  ->  "Привет, Мария!"
solve("Иван")   ->  "Привет, Иван!"
```

Обратите внимание на точность: слово «Привет», запятая, **пробел**, имя,
восклицательный знак. Лишний или пропущенный пробел — уже другой ответ.

Заготовка возвращает приветствие без имени, поэтому не сходится ни на одном.

**Верните приветствие с именем.**

## Сдано, если

- функция возвращает текст, а не печатает его;
- все пять имён совпали.

В задании показаны два имени, проверка прогонит пять. Вписать готовый ответ
не выйдет: остальные три вы не видите.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | заготовка и `TODO`, в котором написано, что набрать |
| `starter/advanced/` | заготовка и пример вызова |
| `starter/pro/` | только контракт функции |

## Если застряли

Текст в кавычках склеивается плюсом: `"а" + "б"` даёт `"аб"`. Имя лежит в
переменной `name`, кавычки вокруг неё не нужны — это уже текст. Соберите три
части: то, что до имени, само имя и то, что после.
