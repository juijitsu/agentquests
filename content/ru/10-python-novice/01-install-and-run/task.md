# Задание · Поздороваться по имени

## Что нужно сделать

В файле `agent.py` лежит одна функция:

```python
def solve(name: str) -> str:
    return "Привет!"
```

Ей передают имя, она обязана вернуть приветствие **с этим именем внутри**.

```
solve("Мария")  ->  "Привет, Мария!"
solve("Иван")   ->  "Привет, Иван!"
```

Ответ сверяется посимвольно: слово «Привет», запятая, **пробел**, имя,
восклицательный знак. Лишний или пропущенный пробел — уже другой ответ, и
проверка это заметит.

**Верните приветствие с именем.**

## Почему заготовка не проходит

Она возвращает `"Привет!"` — текст без имени. Он одинаков для всех пятерых,
поэтому не сходится ни с одним. Имя надо взять из параметра `name` и
подставить в ответ.

## Сдано, если

- функция **возвращает** текст, а не печатает его;
- совпали все пять имён.

В задании показаны два имени, проверка прогонит пять. Вписать готовый ответ
не выйдет: остальных трёх вы не видите, и они другие.

## Чего делать не надо

- **Не переименовывайте `solve`** — проверка ищет функцию по этому имени и
  другую не найдёт.
- **Не вписывайте имя человека в текст.** `return "Привет, Мария!"`
  запустится и даже пройдёт первое имя, но провалит остальные четыре.
- **Не берите `name` в кавычки.** `"name"` — это четыре буквы, а не значение.
- **Не пишите `print`.** На экране будет выглядеть правильно, а вернётся
  пустота, и первая строка вердикта скажет «вернулся текст: нет».
- **Не стирайте четыре пробела** в начале строки: питон по ним понимает, что
  строка внутри функции.

## Выберите сложность

## Если застряли

Ответ собирается из трёх кусков, и склеиваются они плюсом:

```
"Привет, "   +   name   +   "!"
   текст        ярлык       текст
```

Текст — в кавычках, ярлык — без. Пробел после запятой стоит **внутри**
кавычек, иначе слова слипнутся.

Если совсем не идёт — на странице решения есть звезда в углу. Она смотрит на
последний прогон и подсказывает по нему: называет условие, которое не сошлось,
и что с ним делать.
