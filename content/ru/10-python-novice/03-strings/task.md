# Задание · Метка на доске

## Что нужно сделать

Диспетчер пишет метку рейса на доске от руки, а потом её переносят в систему
как есть. Приходит она грязной: по краям бывают лишние пробелы и переводы
строк, регистр вперемешку. Заканчивается метка двузначным номером рейса.

Соберите из метки короткий код по трём правилам:

1. убрать пробельные символы **по краям** — внутри ничего не трогать;
2. перевести в заглавные;
3. взять три первых символа и два последних, склеив их подряд.

```
solve("  dallas run 47 ")  ->  "DAL47"
solve("memphis run 08")    ->  "MEM08"
solve("  Reno Run 12")     ->  "REN12"
solve("OMAHA RUN 33")      ->  "OMA33"
```

Три первых символа дают город, два последних — номер рейса.

**Обратите внимание:** правило про три первых символа означает буквально три
первых символа очищенной строки. Среди скрытых меток есть такая, где первое
слово короче трёх букв, — тогда в код попадёт и пробел. Это не ошибка, а
правило.

## Почему заготовка не проходит

Она вызывает `text.strip()` и `text.upper()`, но результат никуда не кладёт.
Строки в Python не меняются: метод возвращает новую строку, а старая остаётся
прежней. Поэтому режется по-прежнему грязная метка.

Заготовка совпадает ровно на одной метке из десяти — на той, что и так пришла
чистой и заглавными.

## Сдано, если

- функция возвращает текст, а не печатает его;
- совпали все десять меток.

В задании показаны четыре, проверка прогонит десять. Среди скрытых есть метки
с переводами строк по краям и с пробелами только справа — подогнать ответ под
показанные не выйдет.

## Чего делать не надо

- **Не убирайте пробелы срезом** вроде `text[2:-1]`: у разных меток разное
  число пробелов по краям.
- **Не выкидывайте пробелы внутри метки.** Убрать нужно только края.
- **Не режьте `text`** после уборки — режьте то имя, в которое уборка легла.
- **Не пишите метод без скобок:** `text.strip` — это сам метод, а не строка.

## Если застряли

Метод строки — не приказ, а вопрос: он не меняет строку, а отвечает новой.
Значит после каждого вызова должно остаться имя, в которое ответ положили, —
и резать надо именно его.
