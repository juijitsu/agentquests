# Задание · Прибавить порожний пробег

## Что нужно сделать

С диспетчерской доски приходит пробег под грузом — текстом, одними цифрами,
без пробелов и знаков. К каждой заявке добавляется порожний пробег до места
погрузки: всегда 60 миль.

Верните одну строку: пробег как он пришёл, затем ` + 60 = `, затем сумму.

```
solve("1450")  ->  "1450 + 60 = 1510"
solve("300")   ->  "300 + 60 = 360"
```

Пробелы вокруг плюса и равно — по одному. Ответ целиком текст.

**Обратите внимание:** пробег в ответе встречается дважды. Слева — таким,
каким пришёл. Справа — уже внутри суммы. В этом всё задание.

## Почему заготовка не проходит

Она делает `miles + "60"`. Оба куска текст, поэтому плюс их склеивает:
получается `"145060"` вместо `1510`. Программа не падает, ответ неверный.

## Сдано, если

- функция возвращает текст, а не печатает его;
- совпали все шесть заявок.

В задании показаны две, проверка прогонит шесть. Среди скрытых есть такие,
где сумма длиннее пробега и где цифра входа в сумме не встречается вовсе, —
подогнать ответ под примеры не выйдет.

## Чего делать не надо

- **Не ставьте кавычки вокруг 60**, чтобы убрать `TypeError`. Ошибка уйдёт, а
  ответ станет неверным молча — это и есть заготовка.
- **Не превращайте в число весь ответ:** в нём не одни цифры.
- **Не трогайте `miles` слева:** он должен остаться ровно таким, каким пришёл.

## Если застряли

Плюс делает разное в зависимости от того, что по бокам: два текста склеивает,
два числа складывает. Значит перед сложением обе части должны стать числами —
`int(текст)`, — а перед склейкой обратно текстом — `str(число)`.
