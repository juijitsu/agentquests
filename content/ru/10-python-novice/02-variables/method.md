# Метод · Как решать, по шагам

## Шаг 1. Запустите заготовку как есть

Она работает и ошибается. Вердикт:

```
✓ вернулся текст: да
✗ совпало заявок: 0 из 6
✗ первое расхождение: на пробеге «1450»
    ждали:    1450 + 60 = 1510
    получили: 1450 + 60 = 145060
                           ^
```

Стрелка стоит там, где ответы разошлись. Слева от неё всё совпало, дальше
пошли лишние цифры: вместо суммы приклеились цифры шестидесяти.

## Шаг 2. Найдите место, где текст надо сделать числом

В заготовке написано:

```python
    total = miles + "60"
```

`miles` — текст, `"60"` — тоже текст, поэтому плюс склеивает. Нужно, чтобы
слева и справа были числа.

## Шаг 3. Три строки вместо одной

```python
    loaded = int(miles)
    total = loaded + 60
    return miles + " + 60 = " + str(total)
```

- `int(miles)` — из текста получилось число, положили в `loaded`;
- `loaded + 60` — оба числа, плюс складывает;
- `str(total)` — число вернулось в текст, чтобы приклеиться к остальному;
- `miles` слева остался нетронутым: он и должен быть таким, каким пришёл.

Заметьте: `60` в вычислении **без кавычек** — это число. А `" + 60 = "` в
ответе **в кавычках** — это текст, который просто показывают. Одна и та же
шестёрка в двух разных ролях.

## Шаг 4. Запустите

```
✓ вернулся текст: да
✓ совпало заявок: 6 из 6
✓ первое расхождение: все совпали
```

## Шаг 5. Если не сошлось

**Лишние цифры справа** — сложение всё ещё склеивает. Значит `int()` не
применён или применён не к тому.

**`вернулся текст: нет`** — вернули число. Ответ целиком должен быть текстом,
значит сумму надо обернуть в `str()`.

**`TypeError`** — по бокам от плюса разные виды. Смотрите, что слева и что
справа: оба должны быть текстом либо оба числами.

**`ValueError`** — в `int()` попали не одни цифры.

## Шаг 6. Проверьте себя

Не подглядывая, ответьте: почему в ответе `"1450 + 60 = 1510"` число 1450
встречается дважды, но написано по-разному? Если ответ приходит сразу —
уровень усвоен.
