# Задание · Ставка посередине

## Что нужно сделать

На рейс откликнулись перевозчики, каждый назвал свою цену. Ставки приходят
списком целых чисел в том порядке, в каком их прислали. Диспетчеру нужна не
самая низкая и не средняя арифметическая, а та, что окажется **ровно
посередине**, если выстроить все ставки по возрастанию.

Верните эту ставку числом.

```
solve([1200, 900, 1450])                 ->  1200
solve([700, 1100, 950, 800, 1300])       ->  950
solve([2400, 1800, 2150])                ->  2150
```

Количество ставок всегда нечётное, поэтому середина всегда одна.

**Обратите внимание:** во втором примере ответ совпадает с элементом, который
и так стоял посередине списка. Это совпадение, а не правило.

## Почему заготовка не проходит

Она берёт `quotes[len(quotes) // 2]` — середину списка в том виде, в каком он
пришёл. Порядок отправки ставок ничего не говорит об их величине, поэтому
такая середина случайна.

Заготовка совпадает на двух наборах из девяти: на одном середина случайно уже
стояла на месте, во втором наборе всего одна ставка.

## Сдано, если

- функция возвращает целое число, а не печатает его;
- совпали все девять наборов.

В задании показаны три, проверка прогонит девять. Среди скрытых есть набор из
семи ставок, набор из одной и набор, который почти выстроен по возрастанию, но
не до конца.

## Чего делать не надо

- **Не берите элемент по номеру, не выстроив список.** Номер осмыслен только
  вместе с порядком.
- **Не пишите `in_order = quotes.sort()`.** Метод `sort()` переставляет список
  на месте и возвращает `None` — ловить нечего.
- **Не считайте среднее арифметическое.** `sum(quotes) // len(quotes)` — другая
  величина, и на этих данных она другая.
- **Не делите длину одной косой чертой:** `len(quotes) / 2` даёт дробь, а
  индекс обязан быть целым.

## Если застряли

Спросите себя, что означает номер элемента. Он означает место, а место
зависит от порядка. Значит порядок надо задать самому — до того, как брать
элемент по номеру.
