# Метод · Вычерпывать, а не обходить

Разница между двумя циклами — в том, **где стоит вопрос об очереди**.

**Шаг 1. Перенесите вопрос внутрь цикла.** Он должен задаваться перед каждым
событием, а не один раз до всех:

```python
while step < MAX_STEPS:
    pending = run_tool("pending", {})
```

**Шаг 2. Выходите по ответу очереди, а не по концу списка.** `EMPTY` — это и
есть условие завершения смены:

```python
    if pending == EMPTY:
        break
```

**Шаг 3. Берите одно событие, не все.** Остальные никуда не денутся, а к
следующему кругу их состав может измениться:

```python
    event = pending.split(" | ")[0]
```

**Шаг 4. Ограничьте цикл сверху.** Условие выхода теперь зависит от внешнего
мира, а внешний мир может ошибаться. `while step < MAX_STEPS` стоит ровно за
этим: ограничитель из уровня 02 никуда не делся, он просто переехал.

---

Проверка на честность: **посчитайте, сколько раз ваш код спрашивает `pending`.**
Один — вы обходите фотографию. Столько же, сколько событий, — вы вычерпываете
очередь.
