# Метод · Реакция на невыполнимость

Четыре шага.

**Шаг 1. Отделите обычные результаты от обесценивающих.** Не всякий ответ
инструмента равнозначен. «Проехали» продвигает план, «проезда нет» его
обнуляет. Признак различия должен быть явным и проверяемым:

```python
if "проезда нет" in result:
```

**Шаг 2. Запросите новый план, сообщив, что сломалось.** Не что делать —
только что не работает:

```python
new_plan = model.make_plan(question, blocked=call.arguments["leg"])
```

**Шаг 3. Положите новый план в историю.** Он встаёт рядом со старым, а не
вместо него: модель читает последний, а вы при разборе видите оба.

**Шаг 4. Продолжите цикл без изменений.** Ничего перезапускать не нужно —
следующая итерация возьмёт актуальный план и пойдёт по нему.

---

Проверка на честность: удалите из своего кода всё, что называет конкретные
города, кроме тех, что пришли из ответов инструментов. Если решение перестало
работать — вы написали ветвление, а не перепланирование.
