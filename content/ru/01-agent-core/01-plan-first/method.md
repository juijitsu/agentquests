# Метод · Отделить планирование от выполнения

Три шага. Порядок важен: планирование целиком предшествует выполнению.

**Шаг 1. Получите план до первого вызова инструмента.** Не по ходу дела, а
отдельным действием, пока ничего ещё не произошло:

```python
plan = model.make_plan(question)
```

**Шаг 2. Положите план в историю отдельным сообщением.** Не подмешивайте его в
текст вопроса — тогда он потеряется среди остального. Отдельная роль делает план
видимым и в логе, и для модели:

```python
messages.append({"role": "plan", "content": plan})
```

**Шаг 3. Выполняйте, сверяясь со списком.** Цикл не меняется — меняется то, что
модель теперь видит в истории. Она сама идёт по пунктам, потому что знает, из
чего состоит задача.

---

Проверка себя: напечатайте план перед циклом. Если по нему нельзя заранее
сказать, сколько будет вызовов инструментов, план слишком расплывчат.
