# Смена 1 · Ответ про первое звено

Клиент спрашивает, сколько всего идёт груз от границы до Ньюарка. Диспетчер
проверяет первое звено и отвечает: шесть часов.

Шесть часов — это только Laredo. Дальше Dallas, Chicago и Newark.

```
python engine/check.py content/ru/01-agent-core/01-plan-first/starter/novice/agent.py
```

Первая строка проверки покажет, сколько звеньев агент вообще посмотрел.

Обратите внимание: агент не упал и не зациклился. Он уверенно ответил числом —
просто не тем, которое спрашивали. Такое находят клиенты, а не разработчики.

**Сделайте так, чтобы агент сначала получил план, а потом прошёл его целиком.**

## Сдано, если

- проверены все четыре звена;
- в ответе сквозной срок по всему маршруту;
- уложился в 6 итераций.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | цикл целиком, место для плана помечено `TODO` |
| `starter/advanced/` | цикл без планирования, добавить самому |
| `starter/pro/` | контракт и условие |

## Если застряли

Модель следует плану, только если видит его в истории. Посмотрите, какой ролью
кладутся в историю остальные сообщения, и добавьте план своей.
