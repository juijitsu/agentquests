# Метод · Смысловое условие завершения

Три шага.

**Шаг 1. Сформулируйте цель проверяемо.** Не «доставить груз», а «в ответе
встречается Newark». Условие должно быть таким, чтобы код мог его вычислить,
а не таким, чтобы человек мог его оценить.

**Шаг 2. Проверяйте цель там, где раньше выходили.** Место то же — момент, когда
модель перестала просить инструменты. Изменился смысл: раньше это был выход,
теперь это развилка.

```python
if not response.tool_calls:
    if цель_достигнута(response.text):
        return response.text, step
    ...продолжаем...
```

**Шаг 3. Дайте модели новое положение дел.** Она не помнит, где вы находитесь.
Добавьте в историю сообщение с текущим состоянием, иначе следующая итерация
повторит предыдущую.

---

Признак, что условие выхода написано неверно: агент отвечает быстро и уверенно,
а число выполненных шагов меньше ожидаемого. Считайте шаги — они не врут.
