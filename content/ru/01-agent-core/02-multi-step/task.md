# Смена 2 · Доехали до Далласа

Диспетчерская отдаёт маршрут по одному пункту: узнать, что после Далласа, можно
только доехав до Далласа. Груз надо довезти до Ньюарка.

Агент доезжает до Далласа и отвечает: «Доехали до Dallas».

```
python engine/check.py content/ru/01-agent-core/02-multi-step/starter/novice/agent.py
```

Посмотрите на первую строку проверки — сколько пунктов пройдено. Агент не упал
и не ошибся: он честно сделал шаг и честно о нём отчитался. Просто шаг — это не
вся задача.

**Сделайте так, чтобы цикл продолжался до Ньюарка.**

## Сдано, если

- пройдены все три перегона;
- в ответе есть Newark;
- уложился в 10 итераций.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | цикл целиком, место выхода помечено `TODO` |
| `starter/advanced/` | цикл без проверки цели |
| `starter/pro/` | контракт и условие |

## Если застряли

Модель не помнит, где вы находитесь: она видит только историю. Если продолжаете
цикл — скажите ей, до какого города доехали.
