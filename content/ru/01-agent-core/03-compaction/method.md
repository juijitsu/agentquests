# Метод · Собрать окно

Три шага.

**Шаг 1. Выделите то, что нужно всегда.** Пройдитесь по задаче и спросите про
каждый факт: понадобится ли он на последнем шаге? Тариф — да. Отчёт о втором
перегоне — нет.

**Шаг 2. Соберите окно из постоянной части и хвоста.** Постоянное идёт первым,
свежее — следом:

```python
def window(history):
    return [условие] + history[-(WINDOW - 1):]
```

Заметьте `WINDOW - 1`: место под постоянную часть надо оставить, иначе окно
переполнится ровно на одно сообщение.

**Шаг 3. Проверьте на длинной задаче.** Короткая помещается в окно целиком и
ничего не докажет. Ошибки сворачивания видны только тогда, когда история
действительно не влезает.
