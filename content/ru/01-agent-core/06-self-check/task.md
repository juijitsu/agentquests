# Смена 6 · Маршрут, который не успевает

Клиент просит доставку за сорок восемь часов. Агент собирает маршрут из четырёх
перегонов и рапортует: «Маршрут собран. Итого 61 ч.».

Шестьдесят один — это не сорок восемь.

```
python engine/check.py content/ru/01-agent-core/06-self-check/starter/novice/agent.py
```

Посмотрите на первую строку проверки: перегоны все на месте, данные верные,
ошибок не было. И результат всё равно не годится — просто никто не сравнил его
с условием.

**Добавьте ревизию перед выдачей.**

Сравнивать должна модель. Если условие клиента появится в вашем коде числом, вы
напишете валидатор для одного требования, а у клиента их будет пять.

## Сдано, если

- проверены все четыре перегона;
- ревизия проведена ровно один раз;
- в ответе сказано, что маршрут не укладывается;
- уложился в 8 итераций.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | место ревизии помечено `TODO` с подсказкой про review |
| `starter/advanced/` | задан только наводящий вопрос |
| `starter/pro/` | контракт и запрет на сравнение в коде |

## Если застряли

Ревизии нужны два предмета: что получилось и что просили. Второе лежит в
аргументе `question` и никуда не девалось.
