# Смена 10 · Диспетчер целиком

Финал трека. Никаких новых приёмов — всё, что нужно, вы уже проходили. Новое
только одно: работает всё одновременно.

Смена начинается с трёх событий. Разбор поломки рождает четвёртое — наём
перевозчика за тройную цену. Оно необратимо, поэтому идёт человеку. Человек
соглашается. Процесс умирает ровно между его «да» и исполнением.

```
python engine/check.py content/ru/01-agent-core/10-boss/starter/novice/agent.py
```

Заготовка нарушает первые три условия, и проверка показывает это построчно —
чините по одному, каждая строка вердикта относится к своему уровню. Четвёртое
она соблюдает случайно: обход снимка конечен сам по себе. Живое чтение отнимет
это свойство, и ограничитель придётся поставить самому.

## Сдано, если

- разобраны все четыре действия, включая рождённое по ходу смены;
- человека потревожили только из-за необратимого;
- обращение к нему было одно, а не два;
- ни одно согласование не прошло вслепую;
- отчёт называет верное число;
- второй заход уложился в 6 итераций.

## Выберите сложность

| Папка | Что дано |
|---|---|
| `starter/novice/` | четыре `TODO`, каждый с номером уровня, откуда навык |
| `starter/advanced/` | список четырёх условий и код, нарушающий все |
| `starter/pro/` | контракт и критерий приёмки |

## Если застряли

Разбирайте по одной строке вердикта, а не всё сразу. Порядок, в котором они
идут, совпадает с порядком действий внутри круга: сперва очередь, потом
человек, потом исполнение.

## После этого уровня

Агентный трек закончен. Вы умеете строить агента, который планирует,

перезапуск и знает, когда позвать человека.
