# Метод · Один круг, четыре условия

Весь диспетчер — это один цикл. Разница между рабочим и нерабочим — в четырёх
строчках внутри него.

**Круг начинается с вопроса миру, а не с памяти о нём.**

```python
pending = run_tool("pending", {})
if pending == EMPTY:
    break
```

Выход по ответу очереди — это и есть условие завершения смены. Снимок,
сделанный при побудке, к третьему кругу описывает прошлое.

**Цикл всё равно ограничен сверху.**

```python
while step < MAX_STEPS:
```

Условие выхода переехало наружу, и внешний мир может ошибаться. Ограничитель из
уровня 02 страхует именно от этого.

**Человека беспокоят по признаку, а не по привычке.**

```python
if model.judge(action) and action not in APPROVED:
    run_tool("ask", {"name": action})
    APPROVED.append(action)
```

Два условия в одной строке, и оба обязательны. Первое отсекает рутину, второе —
повтор после краха. Уберите любое, и человека потревожат зря.

**Выполнение — последним.**

```python
run_tool("handle", {"name": action})
```

До этой строки решение ещё можно отменить. После — нет.

---

Проверка на честность, одна на все четыре: **представьте, что процесс умирает
на каждой строке цикла по очереди.** Для каждой смерти ответьте, что увидит
агент при следующем запуске. Если хоть раз ответ «спросит человека второй раз»
или «разберёт действие дважды» — состояние записано не там.
