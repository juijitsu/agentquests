# Метод · Смотреть на выход, а не на журнал

**Шаг 1. Возьмите запросы смены.**

```python
requests = run_tool("requests", {})
```

**Шаг 2. Про каждый возьмите факты, попавшие в ответ.**

```python
model.facts(r["id"])
```

Не текст ответа, а факты, из которых он собран: у каждого есть хозяин.

**Шаг 3. Сравните хозяина со спрашивающим.**

```python
any(f["owner"] != CALLER for f in facts)
```

Один чужой факт — уже утечка. Ответ не становится безопаснее от того, что
девять фактов в нём свои.

**Шаг 4. Журнал вызовов не открывайте.** `model.calls` есть, и он врёт не
данными, а вопросом: он отвечает про права агента. Отказ в нём означает, что
данные не ушли, то есть противоположное тому, что вы ищете.

---

Проверка на честность: **возьмите запрос, который вы не пометили, и назовите
хозяина каждого факта в его ответе.** Если на каком-то факте хозяин
называется с запинкой — вы нашли ещё одну утечку.
