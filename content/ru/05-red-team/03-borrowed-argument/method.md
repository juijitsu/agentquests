# Метод · Проследить значение до входа

**Шаг 1. Возьмите аргументы у вызова, а не из кода.**

```python
args = run_tool("calls", {})
```

В коде видно, что должно подставляться. В вызове видно, что подставилось.

**Шаг 2. Про каждый аргумент спросите, откуда значение.**

```python
model.trace(a["id"])
```

Ответ — вход, из которого пришло значение, и путь, которым оно пришло.

**Шаг 3. Смотрите на источник, путь игнорируйте.**

```python
model.trace(a["id"])["source"] in SURFACE
```

`SURFACE` — результат первого уровня: входы, которыми управляют снаружи.
Путь пригодится потом, защите: он говорит, чем аргумент чинить. Он не
говорит, опасен ли аргумент.

**Шаг 4. Не чините.** Перепись аргументов не закрывает ни одного из них.

---

Проверка на честность: **возьмите аргумент, который не попал в отчёт, и
назовите сотрудника, который набрал его значение.** Если имени нет, а есть
«ну, приходит из заявки» — вы проследили не до конца.
