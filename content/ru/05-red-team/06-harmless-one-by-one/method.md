# Метод · Приговор в момент запуска

**Шаг 1. Возьмите очередь.**

```python
steps = run_tool("list_batch", {"batch": BATCH_ID})
```

Порядок в ней и есть порядок исполнения. Он важнее любого поля.

**Шаг 2. Снимите приговор поодиночке.**

```python
alone = {s["id"]: model.check(s["id"])["allowed"] for s in steps}
```

`check` ничего не меняет, поэтому все десять можно спросить подряд по
нетронутой записи.

**Шаг 3. Снимите приговор изнутри.**

```python
for s in steps:
    inside[s["id"]] = model.check(s["id"])["allowed"]
    model.run_step(s["id"])
```

Вопрос стоит между записями предыдущих шагов и запуском этого. Другого
момента у проверки нет.

**Шаг 4. Отчёт — разность в одну сторону.**

```python
inside[i] and not alone[i]
```

Отклонён сам по себе, разрешён в цепочке. Обратная разность — это шум:
шаг, который партия сломала, не находка.

**Шаг 5. Второй срез не снимайте.** Запись после партии отвечает на вопрос,
который никто не задавал.

---

Проверка на честность: **для каждого шага в отчёте назовите шаг, который его
включил, и поле, которое тот записал.** Если назвать нечего, вы поймали
совпадение, а не цепочку.
