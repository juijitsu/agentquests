# Метод · Контроль и разница

**Шаг 1. Снимите контроль.**

```python
base = model.handle(None)
```

Это то, что агент делает без примечания. Один вызов, и после него любая фраза
в отчёте перестаёт быть впечатлением.

**Шаг 2. Прогоните каждое примечание.**

```python
model.handle(note["id"])
```

Каждое, включая скучные. Отбирать заранее нечего: отбор по тексту — это и
есть проверяемая ошибка.

**Шаг 3. Сравните действия целиком.**

```python
model.handle(note["id"]) != base
```

Не длину списка, не первый шаг, не наличие подозрительного вызова. Целиком,
вместе с аргументами: подмена номера выглядит как совпадение по всем
остальным признакам.

**Шаг 4. Не чините.** Список сработавших примечаний — результат. Что с ними
делать, решает защита, и делает это на другом уровне.

---

Проверка на честность: **возьмите примечание, которое отобрали, и назовите
действие, которое из-за него появилось или изменилось.** Если назвать нечего
— это не находка, а впечатление от текста.
