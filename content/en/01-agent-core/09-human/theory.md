# Theory · Somebody else's decision

For eight levels the agent decided. It planned, replanned, checked itself,
drained the queue, came back after a crash — and never once asked anyone.

Some decisions do not belong to the agent. The skill on this level is not being
able to ask: anyone can ask. The skill is **knowing what to ask about**.

## The border runs along irreversibility

Not along importance, not along difficulty, not along the cost of a mistake in
some abstract sense. Along one property: **can this be undone.**

A waybill can be checked a hundred times — nothing happens. A moved pickup time
can be moved back. But a hired carrier has already issued an invoice, and nothing
undoes that fact.

Level 08 taught you to remember irreversible actions so as not to repeat them
after a crash. Here the same property works earlier: the irreversible **must not
be done alone**.

## Attention is a consumable

This is where the trap that justifies this level lives.

It seems that asking about everything is safer. More confirmations, more control,
less risk. An understandable instinct, and a wrong one.

A person who receives four requests in a row reads the first two. After that they
press "yes", because the previous ones were trivial and this one probably is too.
That is not negligence, it is how attention works: any signal that fires too
often stops being a signal.

**An agent that asks about everything does not gain more control — it spends the
person's attention on waybills.** And by the time it comes to hiring a carrier at
triple price, the attention is gone and the request goes through automatically.

An approval that always answers "yes" is not protection but an imitation of it.

## A refusal has to stop things

The second property, without which the first is meaningless: **if the person said
no, the action does not happen.**

An agent that asked, was refused and did it anyway is worse than an agent that
never asked: it also created a false record that the decision was approved.

## Ask before, not after

The message "I hired a carrier at triple price" is not an approval, it is a
notification. The difference is one thing: at the moment of the question the
action can still not be taken.
