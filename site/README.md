# Сайт AgentQuests

Статический сайт курса. Читает уровни из соседней папки `../content` — источник
правды один, дублирования содержимого нет.

```bash
npm install
npm run dev     # разработка на localhost:3000
npm run build   # статический экспорт в out/
```

Публикуется на GitHub Pages рабочим процессом `.github/workflows/pages.yml`
при каждом пуше в main.

Начертания системные: подключение шрифтов сделало бы сборку зависимой от сети,
а у проекта вся идентичность в том, что ставить ничего не надо.
